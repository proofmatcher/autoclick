# Changelog

All notable releases of AutoClick are documented here.

---

## [1.0.0] — 2025-05-16

### What's new
- Initial public release
- Automatic clicking of Run, Accept, Allow, and Apply buttons in Antigravity IDE
- Dual-engine architecture: Commands API + Chrome DevTools Protocol (CDP) DOM injection
- Real-time sidebar dashboard with live click counter, session stats, and quota tracking
- Plan-aware quota enforcement synced to the AutoClick API
- Session state persistence — AutoClick resumes its previous running state after a window reload
- Port auto-detection — connection warning only appears when a genuine disconnect is confirmed
- Animated stat counters in the sidebar for smooth real-time feedback
- Secure API key authentication with local storage
- Cross-platform support: macOS, Windows, Linux

### Plans available at launch
- Free Trial (500 clicks)
- Pro (5,000 clicks / month)
- Advanced (15,000 clicks / month)
- Advanced Pro (30,000 clicks / month)
- Unlimited
- Lifetime

## Versioning

AutoClick follows [Semantic Versioning](https://semver.org/).

- **Major** — breaking changes or significant feature overhauls
- **Minor** — new features, backward-compatible
- **Patch** — bug fixes and small improvements
